Plate 2

What happens when the water gets too warm

The same path runs for low pH and low water level. The AI is only asked once per new problem, and the built-in rules answer if the AI is unreachable.

sequenceDiagram
  participant S as Sensors
  participant E as ESP32
  participant D as Firebase DB
  participant F as Cloud Function
  participant A as Claude API
  participant U as Dashboard
  S->>E: 30.6 °C (Betta range 24–28 °C)
  E->>E: Local check: CRITICAL → buzzer + LCD
  E->>D: write /live and /history
  D->>F: onLiveReading trigger
  F->>F: Evaluate vs fish profile → Critical
  F->>D: open alert
  F->>A: readings + profile + recent trend
  A-->>F: causes, actions, urgency
  F->>D: save recommendation
  D-->>U: live update: alert + care steps
  U->>D: owner taps "Feed now" or changes schedule
  D-->>E: device reads command within 3 s

Plate 5

Build order

Test each part alone before combining. When something fails, you then know which part caused it.

Stage 1

ESP32 alone

  • Install the ESP32 board package
  • Upload Blink and confirm the LED
  • Install CP2102/CH340 driver if no port
Stage 2

One sensor at a time

  • DS18B20, then pH, then ultrasonic
  • Check each in Serial Monitor
  • −127 °C means a wiring fault
Stage 3

Outputs

  • Servo sweep test on the 5V supply
  • LCD shows text (try 0x3F if blank)
  • Buzzer beeps
Stage 4

Feeder

  • Drum with one hole on the servo horn
  • Weigh 20 portions, adjust the hole
  • Use pellets, not flakes
Stage 5

Mount on the tank

  • Ultrasonic ≥ 25 cm above the water line
  • Probes underwater, away from the heater
  • Electronics boxed, cables with drip loops
Stage 6

Calibrate and connect

  • cal7 in pH 6.86, cal4 in pH 4.00
  • Fill in config.h, upload firmware
  • Check readings on the dashboard
